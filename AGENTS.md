# nanoboard

A minimalist, local-first project management workspace: kanban board, whiteboard (Excalidraw), calendar, and sticky notes. There is no server — all data lives in the browser's IndexedDB via Dexie. pnpm + Turborepo monorepo with a single web app.

## Structure

- `apps/web/` — the only app: React 19, Vite, TanStack Router, Tailwind CSS 4, PWA.
  - `src/routes/` — TanStack Router file-based routes. `src/routeTree.gen.ts` is generated by the router plugin; never edit it.
  - `src/lib/db/` — the Dexie data layer: schema, per-entity tables, queries. All persistence goes through here.
  - `src/lib/editor/` — TipTap rich text; `src/lib/backup/` — export/import.
  - `src/components/` — feature components (`kanban-board/`, `whiteboard/`, `stickies/`, `calendar/`, …) and shadcn primitives in `src/components/ui/` (aliases in `components.json`).
  - `src/store/` — Zustand stores; plus `src/hooks/` and `src/constants/`.
- `packages/` — shared config only: `@repo/eslint-config`, `@repo/typescript-config`.
- `.scratch/` — local issue tracker (gitignored).
- `docs/agents/` — how the agent skills use the issue tracker and domain docs.

## Commands

From the repo root:

- `pnpm install` — requires Node ≥ 24.20; pnpm is pinned via `packageManager` (Corepack).
- `pnpm dev` — dev server at http://localhost:5173.
- `pnpm build` — includes the typecheck: `apps/web` runs `tsc` (noEmit) before `vite build`.
- `pnpm lint`, `pnpm test`, `pnpm format`.

Focused: `cd apps/web && pnpm test` runs Vitest over `src/**/*.test.{ts,tsx}`.

## Guidelines

- Local-first, no backend: never add network calls or server state; reads and writes go through `src/lib/db/`.
- Path alias `@/` → `apps/web/src/`, wired into tsconfig paths and both the Vite and Vitest resolve aliases.
- Tests run in plain Node (no DOM): `fake-indexeddb` replaces IndexedDB via the helper in `src/lib/db/test-db.ts`. The Vitest config deliberately does not reuse `vite.config.ts` — don't load the app build chain from tests.
- PWA precache: chunks over 400 kB (the Excalidraw subtree) are excluded from install-time precache and served via CacheFirst runtime caching. Read the comment in `apps/web/vite.config.ts` before touching workbox options.
- TypeScript is strict with `noUnusedLocals`, `noUnusedParameters`, and `noImplicitReturns`; ESLint turns off only `@typescript-eslint/no-non-null-assertion`.
- Theming (dark mode) is CSS variables in `src/index.css`.
